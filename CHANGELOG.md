# bases-view-tabs

## 1.3.0

### Minor Changes

- Each base now opens in the view that you selected last. A link to a different view still opens that view. Turn off Remember the last view in Settings to open the first view again. This feature is free.

## 1.2.1

### Patch Changes

- 6e62806: Pin view (Pro) and the icon items of the tab menu can now be selected without Pro. They show how to get Pro, with a Sponsor on GitHub button, and save nothing.

## 1.2.0

### Minor Changes

- After a minor or major update, Bases View Tabs opens one What's new tab in the background. The tab and settings card suggest other NoteMods plugins and Zovo Chat and link to notemods.com for feedback ([privacy](https://notemods.com/privacy/)). The tab sends no data. Turn the tab off in Settings. Add the Send feedback command. The plugin makes no new network requests.

## 1.1.0

### Minor Changes

- b7d2c64: Add visible Base view tabs with keyboard navigation, free wrapping, and optional Pro pins and icons.
